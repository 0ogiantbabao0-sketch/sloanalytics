# スマホ実機での確認

スマホとPCを同じWi-Fiに接続し、PCで最新版のアプリを起動します。クラウド開発環境のサーバーは、この方法ではスマホから接続できません。

## PCで起動

Node.js 24系をインストールし、最新版のソースを展開した `sloanalytics` フォルダーをターミナルで開いて実行します。

```sh
npm ci
npm run db:setup
npm run dev
```

起動したターミナルは開いたままにします。終了は Ctrl+C です。デモデータは自動生成されます。閲覧だけなら環境変数の設定は不要です。

## スマホで開く

PCのWi-FiのIPv4アドレスを確認します。Windowsでは `ipconfig` のWi-Fiアダプター、macOSでは「システム設定 → Wi-Fi → 詳細 → TCP/IP」で確認できます。

スマホのSafariまたはChromeのアドレス欄に `http://PCのIPv4アドレス:3000` を入力します。たとえばPCが `192.168.1.20` なら `http://192.168.1.20:3000` です。このアドレスは例で、実際のPCの値に置き換えます。

接続できない場合は、同じWi-Fiか、ゲストWi-Fiの端末間通信が制限されていないか、PCのファイアウォールがプライベートネットワークのNode.js通信を許可しているかを確認してください。アプリは全ネットワークインターフェースで待ち受ける設定です。

## 確認する操作

1. 「デモ」モードで、対象日を `2026-10-10` にして分析し、結果を表示する。
2. 下部の「探す・比較・台番・保存・管理」をタップし、切り替えられることを確認する。
3. 検索結果で2店舗を比較に追加し、「比較」で結果を確認する。
4. 下へスクロールしてもタブが表示され、画面最下部のボタンがタブに隠れないことを確認する。
5. お気に入りや条件を保存し、「保存」から開く。縦向き・横向きとキーボード表示時も確認する。

保存内容はブラウザごとに保持され、PCとスマホには同期されません。管理の書込み操作には別途管理トークンが必要です。デモの実績収録期間は2025-01-01〜2026-10-09です。

## PCを使わずに確認する場合

スマホからアクセスできる公開URLが必要です。このクラウド開発環境には共有URLを発行する機能がなく、クラウド環境の設定保存・公開もWebアプリの公開にはなりません。

デモ確認用の [Render公開設定とスマホでの手順](render-preview.md) を用意しています。公開先アカウントの接続と、最新版ソースのGitHubへの反映が必要です。

現在のアプリにはNode.js 24と永続ディスクが必要です。利用できるVPSやコンテナホストにデプロイしてください。手順とDockerfileは [運用ドキュメント](operations.md) にあります。静的サイトとして公開するだけではAPIとSQLiteが動きません。
