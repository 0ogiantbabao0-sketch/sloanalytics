# CSV取込仕様

1行は「1ホール・1機種・1営業日」。機種ごとの総差枚と対象台数を入力し、表示時に平均を計算します。

| 列                       | 内容                                             |
| ------------------------ | ------------------------------------------------ |
| data_kind                | `real` または `demo`。取込先DBと一致必須         |
| hall_id                  | 英数字・`_`・`-`、1〜80文字。店舗の永続ID        |
| hall_name / address      | 検証済み店舗名・住所                             |
| lat / lng                | 検証済み緯度・経度。空欄不可                     |
| machine_name             | 正式名推奨。機種名マスタ＋正規化された略称で解決 |
| date                     | 実在する営業日 `YYYY-MM-DD`                      |
| units                    | 集計に含めた台数、1〜10000                       |
| total_diff               | 集計した対象台の差枚合計、整数                   |
| positive_units           | 差枚が0より大きい台数。0〜units、未取得なら空欄  |
| games                    | 1台あたり平均ゲーム数（整数）、未取得なら空欄    |
| source_name / source_url | 提供元と公開HTTP(S) URL。個人トークンを含めない  |
| permission               | 確認した許可根拠・契約・提供条件を記載           |

同じIDの名前は正規化または取得元別の明示的な名寄せで一致する必要があります。別の住所・座標は全体を拒否します。店舗移転等のマスタ更新は今後の専用管理機能の対象で、日別CSVから暗黙に変更しません。

CSVの不正日付、空の必須数値、台数超過、デモ混在、重複行では全体を差し戻します。ID・日付・正規化機種の複合主キーで二重計上を防ぎ、訂正の前後を `data_revisions` に保存します。複数出典は個別の観測レコードとして保持し、最初の出典を採用します。別出典に切り替えるときは管理画面で明示的に採用します。

機種名はNFKC化、空白・区切り記号除去で照合します。初期略称辞書の「カバネリ」は指定要件の「L カバネリ 海門決戦」を指します。世代違いを混ぜないため正式名を推奨します。未知の名称は新しい機種として登録されます。曖昧な類似名を勝手に統合しません。

取り込んだ対象台数は観測日の設置履歴として保存し、翌日以降の設置を推定しません。全機種の網羅を確認できないため、CSV集計を `daily_hall_results` の全店実績に自動変換しません。

出典の信頼度は「提供者申告・未監査」となります。アプリへの取込成功は、情報の真偽・転載許諾を第三者が検証したことを意味しません。利用者が投入前に確認します。

イベント、抽選、台番、特定日、設置履歴の長期有効期間はスキーマとして用意していますが、MVPのCSV取込対象は日別機種実績です。専用フォーマットと管理機能は未実装です。

## 出典付きCSV v2と手動登録

従来の15列は引き続き利用可能です。`public/samples/real-template-v2.csv` には次の追加列があります。従来CSVで列自体を省略した場合、提供元=user、定義=従来の標準、取得日時=登録時刻になります。v2の提供元・定義コード・定義は必ず入力してください。余分な列や重複ヘッダーは誤読を避けるため拒否します。

| 追加列            | 内容                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| provider_id       | `user` または調査候補のID。候補選択は許諾取得を意味しない                                            |
| definition_code   | `machine-daily-v1`。差枚=払出−投入、games=1台平均、プラス台数=差枚>0。他の定義コードは拒否           |
| definition        | 提供元の集計定義・対象範囲・標準定義への変換根拠。意味の違う数値を単にコードだけ付け替えて投入しない |
| retrieved_at      | 実際の取得日時。タイムゾーン付きISO 8601。空欄は登録時刻                                             |
| published_at      | 公開日時。タイムゾーン付きISO 8601。未取得は空欄                                                     |
| source_updated_at | 提供元での最終更新日時。タイムゾーン付きISO 8601。未取得は空欄                                       |

管理画面の「日別機種実績を手動登録」も同じ入力検証を使います。取得方法は `manual` と記録されます。CSVは `csv`、契約済みアダプタは `licensed-csv` です。いずれの経路でも利用許可の根拠が必要です。公開出典URLには認証情報・クエリ・フラグメントを含めず、提供元の公開参照ページを指定します。

複数出典の扱い、名寄せ、契約設定、採用操作は [出典統合の設計と運用](source-integration.md) を参照してください。
