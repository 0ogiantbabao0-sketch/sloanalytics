# データソースと利用制約

| ソース                                  | 用途           | 現状・条件                                                                                                                                                                                              |
| --------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 内部合成データ                          | 開発・動作確認 | 架空の店舗・実績。demo.sqlite専用。実績として利用しない                                                                                                                                                 |
| ユーザー提供CSV                         | 実績登録       | API提供者・権利者の許諾、転載条件、集計定義を利用者が確認して投入                                                                                                                                       |
| 許諾済みHTTPS CSV                       | 定期更新候補   | アダプタ実装済み。ホスト・URLの明示設定が必要。初期状態で取得しない                                                                                                                                     |
| OpenStreetMap                           | 地図タイル     | `https://tile.openstreetmap.org`。地図内に帰属表示。タイルの一括取得・プリフェッチなし。https://operations.osmfoundation.org/policies/tiles/ の利用条件に従う。高負荷運用は適切なタイルプロバイダへ変更 |
| holiday-jp                              | 日本の祝日判定 | npm配布のオープンソース祝日データ。法改正・将来日付は継続更新が必要                                                                                                                                     |
| 公式店舗・P-WORLD・出玉集計／取材サイト | 将来の調査候補 | API・許諾・転載条件・アクセス条件の確認前。取得アダプタを実装／実行していない                                                                                                                           |

指示書の9店舗（キコーナ京都向日店、123＋N大阪本店、エンターテイメントオメガ六地蔵、アミューズ吹田岸辺、キング河原町店、グランキコーナ京都宇治店、BIGディッパー京都駅前店、大東洋梅田店、キング千本店）は調査候補です。営業状況・住所・台数・出玉を正式ソースで検証していないため、実店舗マスタにもサンプル実績にも登録していません。

地図タイル取得時はブラウザからOSMへ通信します。表示領域に対応するタイル座標が送信されます。管理トークンは同一オリジンのインポートAPI以外へ送信しません。

外部APIキーを追加する場合はサーバー側の環境変数のみで保持し、`NEXT_PUBLIC_` を使用しないでください。署名・TLS検証を無効にする回避策は使用しません。
