# 検証記録

検証日：2026-10-10（日本時間）。クラウド環境内、Node.js 24.19.0、Next.js 15.5.27。

## 成功した検証

- `npm ci` によるlockfileからのインストール。
- `npm run db:setup` による初期化と再実行。既存デモを保持し、実DBへ合成実績を投入しない。
- TypeScript型チェック、本番ビルド。
- カレンダー／集計／ランキング／CSV／SQLite検索のロジック・統合テスト：23件成功。
- Playwright 8ケース：デスクトップChromium、iPhone 13相当390pxのChromium。
  - A：長岡京駅・30km・2026-10-10・カバネリ。
  - B：機種指定解除で全機種の組み合わせを表示。
  - C：ホール指定・11日・過去180日。
  - D：3連休以上・最終日・マイジャグラーV。
  - E：2店舗の同機種比較とホール詳細の表表示。
  - 検索条件の保存、PC／モバイル横はみ出し検査。
  - 実データ空状態、未認証取込の拒否。
  - 管理画面から認証付きCSV取込、出典反映、実DBとの分離。

本番モードのHTTP検証も成功：操作例Aは4件、Bは16件、Cは4件、D/Eは4件、実データは0件。各実績の日付が指定条件を満たすことを検査しました。

本番ブラウザでもランキングと地図マーカーの連動、台番ヒートマップと履歴を操作し、JavaScript例外がないことを確認しました。

E2Eは独立した一時DBと一時トークンで実施。開発用DBにテスト用実績を投入していません。

## 環境による未検証項目

- **WebKit／Safari**：Playwrightのブラウザダウンロード先が通信ポリシーで403。既存Chromiumによるモバイル検証は成功していますが、Safari検証済みではありません。
- **OpenStreetMap背景タイル**：`tile.openstreetmap.org` への通信が403。Leafletの地点・範囲・連動は動作し、背景取得失敗を画面に表示します。背景地図は動作確認未完了です。
- 上記の必要ドメインは環境設定ドラフトに追加済み。設定の保存・公開後、該当操作を再実行してください。保存自体は現行ランタイムへの適用・新しいタスクの検証ではありません。
